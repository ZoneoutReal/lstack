# 03 Outline & Draft

**Owner:** Writer · **Runs:** Wed

## Job
An outline, then a full draft using only what the brief supports.

## Inputs
- templates/outline.md + templates/draft.md
- Previous step's file in `pipeline/<week>/`
- `PRINCIPLES.md`

## Output
- `pipeline/<week>/03-outline.md, 03-draft.md`

## Steps
1. Read the inputs. If the previous file is missing or not done, stop silently.
2. Fill the template completely. No placeholders left.
3. Check against the definition of done below.
4. Write the file. That is the handoff.

## Definition of done
Draft follows the outline; every claim traces to the brief; no new sources.
