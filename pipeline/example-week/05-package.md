## Hooks

3. The agent passed the demo. Here's the test it should pass next.

## Thread version (X)
1/ You wouldn't give a new hire admin access on day one. Same for AI agents. 5 checks you can run this afternoon 🧵
2/ Test it on 10 real tasks from last month. Benchmarks shortlist; your tasks decide.
3/ Try to trick it. Plant "ignore your instructions" in a doc. Prompt injection is OWASP's #1 LLM risk.
4/ Least access that works. Read-only first, then one tool at a time.
5/ Log every action. Review a sample weekly.
6/ Anything irreversible needs a human to approve. Every time.
7/ Pass all five, then widen access slowly. Bookmark this.
