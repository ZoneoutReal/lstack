# Outline — How to evaluate an AI agent before you trust it

- **Hook:** You wouldn't give a new hire admin access on day one. Don't give it to an agent either.
- **Promise:** 5 checks, one afternoon.

## Sections
1. Test on your real tasks — claims #3, #5
2. Try to trick it — claim #1
3. Give it the least access that works — claim #4
4. Make every action visible — counterpoint 3
5. Decide what needs a human — claim #2
## Close
Run the 5 checks; widen access only after it passes.
