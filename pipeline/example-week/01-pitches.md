# Pitches — week 2026-W45

## 1. How to evaluate an AI agent before you trust it
- **Reader:** analysts and engineers asked to roll out an agent at work
- **Why now:** agents now take actions (send, buy, merge), not just answer; teams are adopting them faster than they test them
- **Promise:** a 5-check test you can run in an afternoon before giving an agent real access
- **Rank reason:** broad audience, practical, evergreen

## 2. Writing prompts as specs, not wishes
- **Reader:** engineers who prompt daily
- **Why now:** longer agent runs make vague prompts expensive
- **Promise:** a one-page spec template
- **Rank reason:** useful but well covered

## 3. What an "agent" actually is, in one diagram
- **Reader:** architects explaining agents to leadership
- **Why now:** term is overloaded
- **Promise:** one diagram you can reuse
- **Rank reason:** explainer, less actionable
